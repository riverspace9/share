이 문서는 HJW 본부 주문에 공통 계산기를 연결할 때 적용할 탁송비와 배송비 기준을 설명합니다. 현재 backend에는 공통 계산기와 FSMS 호출부가 있고 HJW 호출부는 연결되지 않았습니다.

<Callout variant="warning" title="HJW 연결 전 확인">
활성 본부 판정 기준은 `OrgCompanies.legacy_bp_group IN ('M10','M20')`입니다. `M10`은 직영본부, `M20`은 위탁본부입니다. 공통 계산기는 회사 유형을 판정하지 않으므로 HJW 호출부가 활성 본부를 검증하고 계산 입력을 만들어야 합니다.
</Callout>

## 2. 상차 탁송비

탁송 대상 실물 품목의 수량을 모두 더한 값이 계산단위수입니다. 배송비 품목은 계산단위수에서 제외합니다. 각 수량은 양의 정수여야 하고 합계가 0이면 계산하지 않습니다.

## 3. 하차 배송비

하차 본부의 `legacyBpCode`와 발주의 `dlvyCd`로 배송료 구역을 찾습니다. 배송지코드에서 `REGION_CD`를 구하고 `(BP_CD, REGION_CD)`가 같은 행의 `DLVY_ZONE1`을 사용합니다. 품목 단가는 해당 본부의 `BP_CD` 행을 먼저 사용하고, 없으면 공통 `BP_CD='*'` 행을 사용합니다.

<MermaidDiagram code={deliveryFeeLookupDiagram} title="하차 배송비 조회 흐름" />

### 품목 분류와 단가

<DataTable
  columns={['분류', '현재 코드 분류', '단가와 계산']}
  rows={[
    ['A01 조사용품', '품목코드 앞 3자리 A01', '화환이 없으면 기본료와 추가료, 화환이 있으면 초과 수량의 추가료'],
    ['화환', 'B01ㆍB02ㆍB03ㆍB04ㆍB05ㆍB06ㆍB08ㆍB09ㆍB10ㆍB11ㆍB12ㆍB13ㆍB15ㆍB21', 'A01 추가 수량을 줄이는 수량으로 사용'],
    ['C03 근조기', '품목코드 앞 3자리 C03', "DLVY_ZONE1='1'의 기본료를 수량이 있으면 한 번 추가"],
    ['C04 축기', '품목코드 앞 3자리 C04', "DLVY_ZONE1='1'의 기본료를 수량이 있으면 한 번 추가"],
  ]}
  caption="현재 공통 계산기의 배송비 품목 분류"
/>

```text
화환 수량 = 0
A01 비용 = A01 기본료 + max(A01 수량 - 1, 0) × A01 추가료

화환 수량 > 0
A01 비용 = max(A01 수량 - 화환 수량, 0) × A01 추가료

C03 수량 > 0
C03 비용 = C03 1구역 기본료 1회

C04 수량 > 0
C04 비용 = C04 1구역 기본료 1회

배송비 = A01 비용 + C03 비용 + C04 비용
```

<Callout variant="info" title="미산정과 0원의 구분">
`null`은 경로나 필수 단가가 없어 계산하지 못한 상태입니다. `0`은 계산을 끝낸 정상 0원입니다. FSMS 호출부는 결과가 `null`일 때만 배송비 행을 만들지 않으므로 0원 결과는 비용 행으로 저장합니다.
</Callout>
